# Bản Đồ Đại Lý — Kiên Giang

App quản lý đại lý phân phối (sản lượng tấn, huyện, nông dân).

Trang live: https://khoahuynh020997.github.io/bandodaily/

## Đã sửa (v3)

- Hiện danh sách đại lý theo huyện
- Chạm cả dòng huyện để đổi khu vực
- Bấm icon mắt để ẩn/hiện số tấn
- Dữ liệu mẫu 14 đại lý trên nhiều huyện
